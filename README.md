# E-commerce-dashboard
E-Commerce Sales Data Analysis and Dashboard in Excel

This repository provides a comprehensive approach to analyzing e-commerce sales data using Microsoft Excel. Through this project, users can gain insights into sales performance, identify key metrics, and visualize results with an interactive dashboard.

The repository includes:

Sales Data Cleaning: Guide for preparing raw e-commerce sales data for analysis.
Data Analysis: Steps to analyze sales data, including calculating revenue, profit, order count, and customer metrics.
Dashboard Creation: Instructions to build a visually appealing dashboard that summarizes key metrics and trends for quick insights.
Key Dashboard Features:
Total Sales & Profit: Overview of total revenue, gross profit, and sales over selected periods.
Top Products & Categories: Displays top-selling products and categories by revenue and quantity sold.
Geographic Analysis: Visual breakdown of sales by location or region.
Monthly/Quarterly Trends: Charts showing sales trends over time for identifying seasonality or growth patterns.
Customer Metrics: Insights into customer acquisition, retention, and average purchase value.
Requirements:
Microsoft Excel 2016 or later
Basic knowledge of Excel functions, charts, and pivot tables
